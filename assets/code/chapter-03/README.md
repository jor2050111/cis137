# Chapter 3 Data Pack: Skills Lab 3A Files

Starter files for Skills Lab 3A: The Newsletter Packet. Students open
these in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-3a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `priya-newsletter-brief.txt` | Plain text request from Priya Sharma | All lab parts |
| `newsletter-sources.txt` | Plain text packet of three short sources | Parts 1 and 2 |

## File details

**skills-lab-3a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items. Students
type answers under each task, rename the file
`skills-lab-3a-lastname.md`, and submit that one file.

**priya-newsletter-brief.txt** is Priya Sharma's request for one item
in Copperwind's community newsletter. It states the topic, the
audience, the length and shape, two facts she insists on, one story
she would like to use, and the five things she wants back.

**newsletter-sources.txt** holds three short sources Priya trusts:
session notes from a Tech Help Tuesday, a Copperwind security note,
and an account from a client's front desk. Each source says who wrote
it. Students check any general claim against a real, published source
before relying on it.

The pack ships no AI responses. Students generate every response
live in a tool from the course roster.
