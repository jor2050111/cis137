# Chapter 5 Data Pack: Skills Lab 5A Files

Starter files and working tools for Chapter 5 and Skills Lab 5A:
Repair the Marketing Prompts. Students open these in any text editor
and never retype their contents. The checklists, the repair sheet,
and the card template are tools to keep: copy them for any prompt you
write, in this course or at work.

## File details

**skills-lab-5a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items. It
includes scoring tables, diagnosis tables, repair-sheet blocks, and
card slots for library v2. Students type answers under each task,
rename the file `skills-lab-5a-lastname.md`, and submit that one file.

**copperwind-marketing-prompts.txt** is Mei Lin's request. It holds
the three weak prompts, the facts about Copperwind, the services page
and the new backup service, the rules for all Copperwind marketing
copy, and one internal note. Every repaired prompt may use only these
facts.

**prompt-strategy-checklist.md** lists the nine strategies of the
Prompt Strategy Checklist in order, each with the test you run on a
prompt and the part of a prompt it strengthens. Columns for your marks
and your own examples are blank.

**output-checklist.md** is the five-check form for scoring one
response: did it do the task, right shape, every claim traceable,
nothing added, and tone fits the audience.

**prompt-repair-sheet.md** is one block per repair run: the weak
prompt, the checklist diagnosis, the one change, the repaired prompt,
and the result against the Output Checklist.

**prompt-card-template.md** is the standard prompt card used in every
Part II chapter.

**prompt-library-v1-starter.md** holds three finished Deskside cards
(password reset reply, VPN connection failure first reply, new-hire
device setup checklist) with the Strategies used field left empty for
students to fill. Each card's sample output is a real capture, not
written by the course author: a chat assistant from the course roster,
run once in a fresh conversation. Prompts 18, 19, and 20 in
`docs/execution-logs/chapter-05-responses.md` in the textbook
repository record the tool and the date.

The pack ships no responses students are asked to produce. Students
generate every lab response live in a tool from the course roster.
