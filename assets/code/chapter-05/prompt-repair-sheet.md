# Prompt Repair Sheet

Fill one block for each run of a repair. Change one thing per run, so
you can attribute each change in score to the strategy that caused it.
Copy the block as many times as you need.

## Repair block

* Prompt name:
* Run number (1 is the weak prompt as written):
* Weak prompt (full text, or "same as the previous run's repaired prompt"):
* Output Checklist score of the weak prompt's response (checks passed, out of 5):
* Checklist diagnosis (the strategy marked Missing that caused the worst failure, and the line that shows the failure):
* The one change (the strategy added, and the exact words added):
* Repaired prompt (full text):
* Tool and date:
* Output Checklist score of the repaired prompt's response (checks passed, out of 5, with the check that changed):
* Result (what improved, what did not, and whether you will keep the change):
