# Chapter 12 Data Pack: Skills Lab 12A Files

Starter files for Skills Lab 12A: The AI Application Project, and the
templates the chapter's Try It Yourself exercises use. Students open
these in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-12a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `capstone-brief-copperwind.txt` | Plain text brief from Mei Lin for the year-ahead recommendation | Lab, Copperwind option |
| `capstone-brief-own-project.txt` | Plain text brief for the student's own IT project | Lab, own-project option |
| `toolkit-starter/` | Folder with one clean copy of every Toolkit template and a starter prompt library (16 files) | Every Try It Yourself, all lab parts |

## File details

**skills-lab-12a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the option choice and the privacy
plan students write before their first prompt, and both Questions &
Analysis items. Students type answers under each task, rename the file
`skills-lab-12a-lastname.md`, and submit that one file. The Toolkit
folder, `toolkit-lastname`, is the second deliverable.

**capstone-brief-copperwind.txt** is Mei Lin's brief: what the
recommendation must contain, the Copperwind facts the student can rely
on, five jobs to consider (four for Work Orders and one to decide
without any tool), what never goes into a prompt, and how she wants it
presented.

**capstone-brief-own-project.txt** sets out what qualifies as an own IT
project, the privacy rule, the same artifacts as the Copperwind option,
and the three lines the instructor approves before Part 2.

**toolkit-starter/** holds one copy of every template the Toolkit
lists, and it is the only place the four Chapter 12 templates
(`verification-trail-readme-template.md`, `ethics-statement-template.md`,
`presentation-outline-template.md`, and `toolkit-readme-template.md`)
ship. Students copy the folder to `toolkit-lastname` in Try It Yourself
12.1 (or lab Part 1, Task 1) and do every fill in that copy, so the
starter stays clean. The Part II, III, and IV templates are copied
unchanged from their chapter packets: `prompt-card-template.md` and
`refinement-log-template.md` (Chapters 4-6), `output-checklist.md`
(Chapter 5), `audit-report-template.md` (Chapter 7),
`ai-use-policy-template.md` (Chapter 8), `use-evaluation-sheet.md`
(Chapter 9), `comparison-matrix-template.md` and
`tool-survey-card-template.md` (Chapter 10), and
`requirements-sheet-template.md`, `work-order-template.md`, and
`selection-decision-template.md` (Chapter 11).
`prompt-library-v2-starter.md` is Chapter 6's starter library, copied
unchanged, so a Toolkit started cold still has a prompt library. Lab
Part 3, Task 5 adds the student's best Work Order prompt to it as a
card.

Every template is blank and works for any project, not only this lab.
The pack ships no AI response. Students generate every response the
lab asks for live in a tool from the course roster. The tool and date
of every sample response in the chapter are in the chapter's execution
log, captured on the textbook author's test setup (not a roster
product).
