# Audit Report

One report per output audited. Write every field for a colleague who
did not see your work. Use counts, never percentages, and quote the
output exactly. A material omission (a fact the reader needs that the
output leaves out) goes in the Recommendation's conditions, or under
Worst finding when it is the worst.
