# Verification Trail README

The Verification Trail is the project's evidence pack: the files a
colleague needs to retrace your work without asking you a question.
This README is the first page they open. It says where each piece
lives and what a person checked. Keep every file name exact, and
write "None" instead of leaving a row blank.
