# Chapter 10 Data Pack: Skills Lab 10A Files

Starter files for Skills Lab 10A: The Help Desk Comparison Matrix, and
the sheets the chapter's Try It Yourself exercises use. Students open
these in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-10a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `fair-test-tasks.txt` | Plain text request from Mei Lin: three help desk tasks, their inputs, and their checks | Try It Yourself 10.3, Fix It 10.1, all lab parts |
| `comparison-matrix-template.md` | Markdown template for one Comparison Matrix (one task) | Try It Yourself 10.2, 10.3, and 10.4, lab Parts 1-3 |
| `tool-survey-card-template.md` | Markdown template for one Tool Survey card | Try It Yourself 10.1, lab Parts 1 and 3 |
| `tool-survey-starter.md` | Markdown Tool Survey with one filled card and three blank ones | Section 10.4, Try It Yourself 10.5, lab Part 3 |

## File details

**skills-lab-10a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items.
Students type answers under each task, rename the file
`skills-lab-10a-lastname.md`, and submit that one file.

**fair-test-tasks.txt** is Mei Lin's request. It gives three Deskside
tasks: a first reply to a printer-offline ticket (with the team's three
steps), a four-bullet summary of a short client update, and a
plain-language explanation of two-step sign-in for a client's staff
(with the facts and Copperwind's standing promise). Each task lists the
checks a good result must pass. The file names no client and holds no
identifiers.

**comparison-matrix-template.md** and **tool-survey-card-template.md**
are blank. The matrix holds one task, its fair test record, a "How you
check it" line for each of the six criteria, a row per tool, and three
"What the matrix shows" lines. The card holds the eight fields of a
Tool Survey card. Both work for any task and any tool, not only this
lab.

**tool-survey-starter.md** is a starter Tool Survey with a review-date
header, three blank cards, and one card for Tool A, the textbook
author's test setup (not a roster product). Its Last tested line gives
the score from the chapter's fair test on Task 1 (two runs). Every line
a vendor can change is left blank, because Tool A is not a product a
student can sign up for. The tool and the full record of those runs
are in the textbook author's capture log, which is not in the data
pack.

The pack ships no AI response. Students generate every response the lab
asks for live in a tool from the course roster.
