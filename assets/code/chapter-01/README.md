# Chapter 1 Data Pack: Skills Lab 1A Files

Starter files for Skills Lab 1A: Map the AI Around You. Students open
these in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-1a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `everyday-systems.txt` | Plain text list of 12 systems to classify | Part 1 |
| `copperwind-ai-inventory.txt` | Plain text pilot brief and inventory of 8 systems | Try It Yourself 1.5, Part 3 |

## File details

**skills-lab-1a-worksheet.md** holds numbered answer spaces for Parts
1-3 and the Questions & Analysis section. Students type answers under
each prompt, rename the file `skills-lab-1a-lastname.md`, and submit
that one file.

**everyday-systems.txt** describes 12 everyday systems without naming
their type. The set mixes rule-based systems, machine learning,
generative AI, and a few that can be argued two ways on purpose, so
the classification task needs reasoning, not matching.

**copperwind-ai-inventory.txt** is Mei Lin's pilot brief to the
student, Copperwind's new AI adoption assistant. It states the
company facts the student may use, lists eight systems (A-H) the
company already runs, and asks for a sorted inventory, a two-item
pilot recommendation, and a staff note that uses only the facts in the
brief. Item E (the password manager) is not AI. Item G (the unofficial
chat assistant) is the one that should raise a policy question.
