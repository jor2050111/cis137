# Chapter 9 Data Pack: Skills Lab 9A Files

Starter files for Skills Lab 9A: The Deskside First-Reply Memo, and the
sheets the chapter's Try It Yourself exercises use. Students open these
in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-9a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `deskside-pilot-numbers.txt` | Plain text report from Mei Lin on the two-week first-reply pilot | All lab parts |
| `technician-notes.txt` | Plain text, five anonymous notes from Deskside technicians | Lab Parts 1 and 3 |
| `use-evaluation-sheet.md` | Markdown sheet for the Use Evaluation's five factors | Try It Yourself 9.2, lab Part 2 |
| `evidence-log-template.md` | Markdown log for outside sources and one checked claim | Try It Yourself 9.3 and 9.4, lab Parts 1 and 3 |
| `memo-template.md` | Markdown template for the Memo | Lab Part 3 |

## File details

**skills-lab-9a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items.
Students type answers under each task, rename the file
`skills-lab-9a-lastname.md`, and submit that one file.

**deskside-pilot-numbers.txt** is Mei Lin's plain report on the pilot:
the Deskside team's size and ticket volume, the service target, the
hand-drafting time, the pilot's counts and drafting time, a description
of the two drafts caught with an invented step, the vendor's price (no
vendor named), and a list of what the pilot did not measure.

**technician-notes.txt** holds five short, anonymous notes from Deskside
technicians about the pilot. Mei Lin removed the names. The notes
disagree with each other in places, on purpose, so a memo has to weigh
them.

**use-evaluation-sheet.md**, **evidence-log-template.md**, and
**memo-template.md** are blank sheets. Each one works for any proposed
AI use, not only this lab.

The pack ships no AI response. Students generate every response the lab
asks for live in a tool from the course roster.
