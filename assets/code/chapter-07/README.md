# Chapter 7 Data Pack: Skills Lab 7A Files

Starter files for Skills Lab 7A: The Pilot Audit, and the template
the chapter's Try It Yourself 7.5 uses. Students open these in any
text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-7a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `copperwind-facts-sheet.txt` | Plain text facts sheet from Mei Lin (the source for every audit) | All lab parts |
| `ai-services-blurb.txt` | Plain text captured draft of Copperwind's services blurb, with the prompt that produced it | Lab Parts 1 and 3 |
| `job-posting-draft.txt` | Plain text captured draft of the Deskside technician job posting, with the prompt that produced it | Lab Parts 2 and 3 |
| `applicant-a.txt` | Plain text fictional applicant profile | Lab Parts 2 and 3 |
| `applicant-b.txt` | Plain text fictional applicant profile | Lab Parts 2 and 3 |
| `audit-report-template.md` | Markdown Audit Report, with an audit table and a paired-runs table | Try It Yourself 7.5, lab Part 3 |

## File details

**skills-lab-7a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items.
Students type answers under each task, rename the file
`skills-lab-7a-lastname.md`, and submit that one file.

**copperwind-facts-sheet.txt** is Mei Lin's list of Copperwind facts:
the company, the two teams and their sizes, support hours, the
service target, what each team handles, the rules for anything
Copperwind publishes, and the facts of the Deskside technician
opening. Every fact carries a number (F1, R1, H1, and so on) so an
audit can point to it. It is the only source for both audits.

**ai-services-blurb.txt** and **job-posting-draft.txt** each open with
a short note from Mei Lin and the exact prompt a Copperwind staff
member sent, then give the response verbatim between "Response
begins" and "Response ends" markers. Each response is a real capture,
not written by the course author: the textbook author's test setup
(not a roster product), run in a fresh conversation. The tool and the
date are recorded in the textbook author's capture log (Prompts 26 and
27), which is not in the data pack. The formatting, the bracketed
placeholders, and the notes at the end of each response are exactly
what the tool returned.

**applicant-a.txt** and **applicant-b.txt** are two fictional
applicant profiles for the Deskside technician opening. They are
identical except for one detail (and the file heading), so students
can run a paired prompt test. Finding the detail is part of the lab.

**audit-report-template.md** gives the seven Audit Report fields in
order, an audit table for the counts, and a table for paired runs. It
is a tool students keep and reuse on any AI output.

The only AI responses in the pack are the two captured drafts. The
pack ships no response a student is asked to produce. Students
generate every one of those live in a tool from the course roster.
