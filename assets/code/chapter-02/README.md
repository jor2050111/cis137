# Chapter 2 Data Pack: Skills Lab 2A Files

Starter files for Skills Lab 2A: Fact-Check the Client Summary.
Students open these in any text editor and never retype their
contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-2a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `copperwind-client-update.txt` | Plain text client update (the source) | Part 3 |
| `copperwind-ai-summary.txt` | Plain text AI summary of the update, with the prompt that produced it | Part 3 |

## File details

**skills-lab-2a-worksheet.md** holds a heading and answer space for
every task in Parts 1-3 and both Questions & Analysis items, with
slots for each prompt, response, and table the lab asks for. Students
type answers under each task, rename the file
`skills-lab-2a-lastname.md`, and submit that one file. Parts 1 and 2
use responses the student generates live in a chat assistant.

**copperwind-client-update.txt** is a one-page update from Dana
Okafor, office manager at Quillmark Property Group, one of
Copperwind's clients, about the company's move from Tempe to
Chandler. It holds the dates, counts, names, and requests that the
summary is checked against. It is the only source for Part 3.

**copperwind-ai-summary.txt** opens with a short note from Mei Lin and
the prompt a Deskside technician sent, then gives the chat assistant's
response verbatim, between "Response begins" and "Response ends"
markers. The response is a real capture, not written by the course
author: a chat assistant from the course roster, run in a fresh
conversation. Prompt 20 in
`docs/execution-logs/chapter-02-responses.md` in the textbook
repository records the tool and the date. Its formatting, including
the hyphen bullets and bold labels, is exactly what the tool returned.
