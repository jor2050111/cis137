# Chapter 6 Data Pack: Skills Lab 6A Files

Starter files for Skills Lab 6A: The Finished Prompt Library, and the
sheets the chapter's Try It Yourself exercises use. Students open these
in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-6a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `priya-newsletter-brief-2.txt` | Plain text request from Priya Sharma | All lab parts |
| `criteria-sheet-template.md` | Markdown sheet for criteria written before the first run | Try It Yourself 6.1, lab Part 1 |
| `refinement-log-template.md` | Markdown log, one row per version | Try It Yourself 6.2 and 6.3, lab Parts 1-2 |

| `prompt-library-v2-starter.md` | Markdown library of three finished Deskside cards | Sections 6.3-6.4, Try It Yourself 6.4 and 6.5, lab Part 3 |

## File details

**skills-lab-6a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items.
Students type answers under each task, rename the file
`skills-lab-6a-lastname.md`, and submit that one file.

**priya-newsletter-brief-2.txt** is Priya Sharma's request for one
newsletter item on two-step sign-in. It states the topic, the audience,
the length and shape, two facts she insists on, one caveat that must
survive, a rule against unsourced numbers, and the three things she
wants back. One line in it is marked as private.

**criteria-sheet-template.md**, **refinement-log-template.md**, and
**two-tool-comparison-sheet.md** are blank sheets. Each one is a tool
students keep and reuse on any prompt, not only in this lab.

**prompt-card-template.md** is the prompt card format every Part II
chapter uses. **library-readme-template.md** gives the sections of a
library README, written for a colleague who never saw the work.

**prompt-library-v2-starter.md** holds the first three cards of
Copperwind's shared prompt library, all for the Deskside team (password reset, VPN connection failure,
shared mailbox access), each with its Strategies used line filled.
Students may use it in place of their own Chapter 5 library. Each
card's Last run line names the date of a real run with the card's
example input, and that run's output sits under the card, so the
library works on its own. The tool and the full record are in the
textbook author's capture log (Prompts 11-13), which is not in the
data pack. The process facts inside the cards are
fictional Copperwind procedures.

The only AI responses in the pack are the three logged last-run outputs
under the starter cards. The pack ships no response a student is asked
to produce. Students generate every one of those live in a tool from
the course roster.
