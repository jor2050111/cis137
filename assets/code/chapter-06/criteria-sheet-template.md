# Criteria sheet

Fill this sheet in before the first run of a prompt. Criteria you write
after you see a draft tend to describe the draft you got, not the job
you needed done. You may change a criterion later. When you do, record
the change at the bottom of this sheet, not in your Refinement Log.

## The job

* Prompt name:
* Job (what the output is for, in one sentence):
* Audience (who reads the output):
* Source of the facts (file, notes, or person):
* Facts that must appear (copy them from the source, word for word when
  the source requires it):

## The criteria

Write three to six criteria. Each one is a single test that passes or
fails on evidence you can point to: a count, a quote, a yes or no.
Mark the ones the output cannot ship without as must pass.

The Output Checklist from Chapter 5 is a good place to start. Make each
item specific to this job:

* Did it do the task?
* Right shape?
* Every claim traceable?
* Nothing added?
* Tone fits the audience?
