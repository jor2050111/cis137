# Rules Sorting Sheet

Use this sheet to sort the rules that bear on an AI use into the four
kinds of rules. One case can fall under more than one kind. Fill one
row per rule, not one row per case.

The four kinds of rules, in order:

* **Law:** binding, with penalties, made by a legislature or a
  regulator.
* **Policy:** an organization's own rules for its people.
* **Guidance:** a framework or standard an organization chooses to
  follow, such as the NIST AI RMF.
* **Ethics:** the principles behind the other three.
