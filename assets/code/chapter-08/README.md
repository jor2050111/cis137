# Chapter 8 Data Pack: Skills Lab 8A Files

Starter files for Skills Lab 8A: The Copperwind AI Use Policy, and the
sheets the chapter's Try It Yourself exercises use. Students open these
in any text editor and never retype their contents.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-8a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `policy-brief.txt` | Plain text brief from Mei Lin | All lab parts |
| `rules-sorting-sheet.md` | Markdown sheet for sorting rules into the four kinds of rules | Try It Yourself 8.1, lab Part 1 |
| `data-policy-reading-sheet.md` | Markdown sheet for reading one vendor's data policy | Try It Yourself 8.3, lab Part 2 |
| `ai-use-policy-template.md` | Markdown template for an AI Use Policy, seven sections | Section 8.4, lab Part 3 |

## File details

**skills-lab-8a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items.
Students type answers under each task, rename the file
`skills-lab-8a-lastname.md`, and submit that one file.

**policy-brief.txt** is Mei Lin's request for Copperwind's first AI Use
Policy. It names who signs the policy, the seven sections it must
cover, the Copperwind facts the policy may use, three situations the
policy must settle, and one question about applicant summaries that
she cannot answer. One line in it is marked as private.

**rules-sorting-sheet.md** is a blank table for sorting each rule that
bears on an AI use by kind: law, policy, guidance, or ethics. It lists
the four definitions at the top. One case can need several rows.

**data-policy-reading-sheet.md** is a blank sheet for one tool and one
plan. Its six fields are what the vendor keeps, training on your input,
retention, deletion, consumer versus business terms, and human review.
Each field has a column for where the answer was found. Students fill
it from the vendor's own pages, not from memory or from another AI
tool.

**ai-use-policy-template.md** gives the seven sections in order
(Purpose, Approved tools, What never goes in, Review before use,
Disclosure, Who to ask, Review date), a table for approved tools, and a
signature line. It asks the writer to label every rule with its kind.

The pack ships no AI response. Students generate every response the lab
needs live in a tool from the course roster. The chapter's sample
responses were captured on the textbook author's test setup (not a
roster product) and are recorded in the author's capture log, which is
not in the data pack.
