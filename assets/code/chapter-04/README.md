# Chapter 4 Data Pack: Skills Lab 4A Files

Starter files for Chapter 4's Try It Yourself exercises and for Skills
Lab 4A: The Deskside Prompt Library. Students open these in any text
editor and never retype their contents. The three tool files (the
card template, the anatomy card, and the type picker) are meant to be
copied and reused after the course.

## Contents

| File | Type | Used in |
| ---- | ---- | ------- |
| `skills-lab-4a-worksheet.md` | Markdown worksheet (the submission file) | All lab parts |
| `deskside-ticket-samples.txt` | Plain text request from Mei Lin and six client tickets | All lab parts |
| `prompt-card-template.md` | Markdown template for one prompt card | Try It Yourself 4.3 to 4.5, Lab Part 3 |
| `prompt-anatomy-card.md` | Markdown card listing the five parts of a prompt and their tests | Try It Yourself 4.1, Lab Part 1 |
| `prompt-type-picker.md` | Markdown table matching jobs to prompt types | Try It Yourself 4.2, Lab Part 2 |

## File details

**skills-lab-4a-worksheet.md** holds a heading and answer slots for
every task in Parts 1-3, starting with the privacy plan students write
before their first prompt, and both Questions & Analysis items.
Students type answers under each task, rename the file
`skills-lab-4a-lastname.md`, and submit that one file.

**deskside-ticket-samples.txt** opens with Mei Lin's request for a
prompt library the Deskside team can share, and what she wants back.
It then holds six client tickets, one for each common Deskside ticket
type: password reset, VPN connection failure, printer offline,
new-hire device setup, slow laptop, and shared mailbox access. Each
ticket gives the client type, the requester, the contact details, and
the client's own words. The tickets are the raw material for prompt
library v1.

**prompt-card-template.md** is the standard prompt card, with its
eight fields in order. The Strategies used field stays blank in
Chapter 4. Chapter 5 fills it.

**prompt-anatomy-card.md** lists the five parts of a prompt (Role,
Task, Context, Format, Constraints) with a one-line test for each, a
blank "Your prompt" column, and a short check to run before sending.

**prompt-type-picker.md** describes the five prompt types (instruction,
question, completion, role play, and example-led) with the job each
one fits, one example each, and what to watch for. Its "Your jobs"
table is blank for students to fill.

The pack ships no AI responses. Students generate every response live
in a tool from the course roster.
