# Prompt Type Picker

Choose the prompt type by the job, not by habit. Read the five types
below, then add a row to "Your jobs" each time you choose a type for a
new job. The runner-up column keeps you honest: if you cannot say why
the runner-up loses, you have not chosen yet.

## The five types

| Type | The job it fits | One example | Watch for |
| --- | --- | --- | --- |
| Instruction | You need a finished thing you can use | Write a 50-word reminder for the book club about Thursday's meeting moving to Room B. | A missing Context part, which the model fills with guesses |
| Question | You need to understand something | Why does a library card renewal need proof of address? | Asking a question when you needed the thing itself |
| Completion | You have the opening and the voice, and need the rest | Finish this note in the same voice: "Thanks for coming out to Saturday's cleanup. Next month we" | The model fills gaps with likely details, so supply the facts first |
| Role play | You need practice, such as rehearsing a hard conversation | You are a parent upset about a canceled game. I am the league coordinator. Stay in character and wait for my reply. | The model playing your side too, so tell it not to |
| Example-led (few-shot) | You need many outputs in one shape or voice | Here are two thank-you notes our owner wrote. Write one more in the same style for a customer who referred a friend. | It copies every habit in the examples, including the ones you did not mean to teach |
