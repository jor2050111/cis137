# CIS137 Glossary

This glossary defines every technical term used in the CIS137 textbook. Each chapter bolds a term at first use, and the Key Terms list at the end of each chapter points you here for review. Every chapter uses these exact definitions. Vendor and product names do not appear here, because the skills outlast any one tool.

## A

AI winter
:   A period when funding and interest in AI collapsed after promised results failed to arrive. The field saw two, in the 1970s and around 1990. The pattern (breakthrough, promise, lag, collapse) is a tool for judging today's claims.

artificial general intelligence (AGI)
:   A hypothetical system that could match human ability across any task it was handed. No such system exists. Every AI tool in use today is narrow AI.

artificial intelligence (AI)
:   A family of techniques for getting computers to do tasks that normally need human judgment, such as recognizing a face, sorting mail, writing a paragraph, or choosing a move. AI is not one technology. The types differ in where their behavior comes from.

## C

chat assistant
:   A generative AI tool you talk to in plain language. It drafts, summarizes, explains, brainstorms, and answers questions. The main tool of this course.

## D

deep learning
:   Machine learning that uses a neural network with many layers. Deep learning made computers good at seeing and hearing, and it is the foundation of generative AI.

## E

expert system
:   A rule-based system from the 1970s and 1980s that captured a specialist's knowledge as hundreds or thousands of if-then rules. Expensive to maintain and brittle outside its narrow domain.

## F

free tier
:   The version of a tool you can use at no cost, with limits such as a daily message cap, a smaller or slower model, or fewer features. Every lab in this course fits inside a free tier.

## G

generative AI
:   AI that produces new content, such as text, images, audio, or video, in response to a prompt. A generative model is a machine learning model whose job is to make rather than to sort.

## I

image generator
:   A generative AI tool that produces a picture from a text prompt. Most also edit a picture you upload.

## L

large language model (LLM)
:   A deep learning model trained on enormous amounts of text to predict which words come next. Large language models are the models behind chat assistants.

## M

machine learning
:   A type of AI that is given examples instead of rules and works out the patterns on its own. The examples are its training data, and the learned patterns form its model.

model
:   The set of patterns a machine learning system learned from its training data, which it uses to decide about something it has never seen before.

multimodal
:   Able to handle more than one kind of input or output, such as text, images, and audio, in one tool or one conversation.

## N

narrow AI
:   AI that does one job, or a cluster of closely related jobs, and nothing else. Every AI tool in use today is narrow, including chat assistants, which do one thing (generate language) across many topics.

neural network
:   A model built from many layers of simple units that each pass a signal to the next layer. The structure behind deep learning.

## P

prompt
:   The request you give a generative AI tool: a question, an instruction, or a description of what you want it to produce.

prompt log
:   A plain text or Markdown file where you record each prompt you send, the tool, the date, the response you received (copied exactly), and your notes on it. The evidence every Skills Lab in this course is built from.

## R

research tool
:   A generative AI tool that answers a question with citations to sources you can open and check. It combines web search with generation.

rule-based system
:   A system that follows instructions a person wrote out in advance: if this, then that. Predictable and explainable, but it fails on any case the rule writer did not foresee.

## T

training data
:   The examples a machine learning system learns from. The model inherits whatever the training data contains, including its mistakes and its bias.

Turing test
:   A test Alan Turing proposed in 1950 as an imitation game: a machine passes if a person conversing with it by text cannot reliably tell it from a human.
